# Personal Finance Tracker

A personal finance application for extracting, categorizing, and analyzing bank transactions from Desjardins (Quebec credit union) PDF statements.

## Key Features

- **PDF Extraction**: Uses Claude Vision to extract transactions from Desjardins credit card statements
- **AI-Powered Categorization**: Leverages natural language rules to automatically categorize transactions
- **Multi-Account Support**: Tracks credit cards, chequing, savings, and investment accounts
- **Validation Workflow**: Transactions are auto-categorized, then manually confirmed or corrected
